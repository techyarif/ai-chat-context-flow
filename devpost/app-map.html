AI Chat Context Flow

A Gemini-only Chrome extension that asks the current conversation for a structured context handoff, then places the result in a fresh chat for you to review.

The extension does not send the continuation draft. The source chat receives the extraction request and Gemini's response; the destination prompt stays editable until you send it yourself.

One handoff, from click to draft

1. Start in a source chat

Click Continue this conversation in new chat. content/content-script.js starts the request.

2. Generate and carry context

background/service-worker.js coordinates Gemini and stores a one-time transfer while the new tab opens.

3. Review before sending

content/gemini-dom.js inserts the snapshot as editable prompt text. You decide whether and when to send.

Reference route through the code

This is a navigation guide, not a claim that we toured these files together.

  1. content/content-script.js — find handleFlowContext to see the button send FLOW_CURRENT_CHAT, and tryInsertPendingContext to see the destination receive the draft.
  2. background/service-worker.js — find handleFlowCurrentChat for current-tab extraction, fresh-tab creation, and the temporary pendingContext transfer.
  3. content/snapshot.js — find buildExtractionPrompt and extractSnapshot for the agreed snapshot headings and response validation. Their behavior is covered by tests/snapshot.test.js.

To change this, start here

  • Button wording and click behavior: content/content-script.js, mountPageControls.
  • Snapshot structure and required sections: content/snapshot.js, buildExtractionPrompt and extractSnapshot.
  • Gemini editor/send/response selectors and safe insertion: content/gemini-dom.js.
  • Button appearance, focus ring, and light/dark colors: content/styles.css.

A practice to reuse

The handoff requirement keeps review and sending under the user's control. The prompt/response tests in tests/snapshot.test.js check the required structure, missing headings, and rendered-heading normalization. On another project, turn an important requirement into an observable result, then test that exact result instead of relying only on an implementation check.

Run it again

  1. Run node --test from the project root to run the built-in tests.
  2. In Chrome, open chrome://extensions, enable Developer mode, choose Load unpacked, and select the folder containing manifest.json.
  3. Open an existing Gemini conversation, refresh the page, and try the handoff button. Inspect the new prompt before choosing to send it.
